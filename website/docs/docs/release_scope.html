What this release contains

This isolated snapshot is prepared from the current working files, including uncommitted development, not from a clean upstream Git tag. SOURCE_SNAPSHOT.json records source and release hashes for copied files. No original source file is edited by release preparation.

The production package excludes the separate cmrbench/diagnostics investigations. Selected scientific-interface tests are included; tests of private IDE files, server assets and unpublished historical fixtures are excluded or removed from the release copy. External repositories, checkpoints, patient arrays, original cohort demographics, notebooks/presentations, reports, logs and private result records are not distributed.

Release-only changes replace machine paths and example subject IDs, remove fixed model-YAML interpreter locations and make interpreter selection configurable through environment variables. Study-specific simulation/Slurm templates retain their scientific settings and must be configured for a new machine/cohort. The model operators, sampling equations and metric definitions are retained.

The public main CSV removes internal task bookkeeping and maps subject IDs to release-specific identifiers. Numeric strings are preserved; the private linkage map remains outside this repo. The public audit removes internal paths. No existing result images or GIFs are included, following the requested quantitative-only initial scope. The qualitative case manifest is empty.

The repository is a draft for local review. No GitHub repo has been created, no Git history is copied and no website is published by this preparation. Set author/affiliation details and a first-party license, resolve the CardioMM sampling redistribution terms in THIRD_PARTY_NOTICES.md, and then upload only this snapshot directory. The private parent folder contains linkage and audit materials and is not an upload target.
